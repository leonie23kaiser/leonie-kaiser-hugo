# Bildnachweise — Blog-Bilder

**Namensschema:** `<Autor/Quelle>-<Keyword>-post<N>.png` — so lässt sich am Dateinamen
sofort erkennen, ob ein bestimmtes Bild (nach Autor) schon für einen Post verwendet wurde,
bevor man es erneut hochlädt. Nicht verwendete Kandidaten tragen das Präfix `backup-` und
keine `-post<N>`-Endung.

**Hinweis zu den KI-Grafiken (Zwischengrafiken Post #2/#3/#5):** Die Originaldatei hier im
Ordner trägt das neue Namensschema, die technisch ausgelieferte WebP/PNG-Version in

bestehenden, rein technischen Dateinamen — eine Umbenennung dort bräuchte Änderungen an
den `<img>`-Pfaden im Artikeltext, ohne für die Autor-Übersicht hier einen Zusatznutzen zu
bringen.
